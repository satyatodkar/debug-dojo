📋 Examination Rules

Rules & Permitted Actions

⏱ Time Limits & Authoritative Deadline

The countdown timer displayed in the header is server-authoritative. Switching tabs, reading hints, or reloading the page will never pause, extend, or reset your examination time.

💡 Hints Usage Policy

You may request up to 3 progressive hints at any point during your active attempt. Hints are non-spoiler conceptual aids designed to prompt your debugging process. Complete solution code is never provided.

🛡 Academic Integrity & Anti-Cheating Controls

  • Anti-Paste Controls: Clipboard paste and drag-and-drop are disabled in the exam editor. Solutions must be typed directly.
  • Activity Auditing: Switching browser tabs, minimizing the exam window, or exiting fullscreen are recorded as integrity events.
  • User Isolation: Attempts belong strictly to the authenticated learner.

🐳 Isolated Execution Sandbox

When you click Run Tests, your Python code is executed inside a disposable Docker container with:

  • Strict 2.0-second timeout per test case.
  • 128 MiB RAM ceiling.
  • Zero network access and a read-only root filesystem.

✓ Final Submission & Evaluation

When you click Submit Answer or Submit Exam, your code is tested against both visible test cases and confidential hidden test cases. Once finalized, the attempt is closed and the final scorecard is displayed.

🟢 Permitted Actions

  • Switching freely between Question, Hints, and Instructions tabs at any time.
  • Running visible tests as many times as you like before submitting.
  • Using the in-editor Tab key for 4-space indentation.
  • Resetting your code to the original starter code if needed.
